# Кредитный кабинет

React и Next.js. Нужен Node.js 20.9 или новее; рекомендуется Node.js 22.

## Запуск

Из корня репозитория:

```sh
cd frontend
npm ci
```

Скопируйте `.env.local.example` в `.env.local` и укажите адрес работающего API:

```env
BACKEND_URL=http://127.0.0.1:8080
```

Указывается адрес сервера без `/docs` и `/api/v1`. Локальный адрес подходит,
только если бэкенд запущен на этом же компьютере. Для общего сервера нужен
его доступный сетевой адрес. После изменения настройки перезапустите фронтенд.

```sh
npm run dev
```

Откройте адрес из терминала, обычно http://127.0.0.1:3000.
Бэкенд запускается отдельно по инструкции в `docs/backend.md`.
Next.js пересылает запросы `/backend/*` на `BACKEND_URL/api/v1/*`.

## Файлы

- `components/Auth.jsx` — вход и регистрация.
- `components/App.jsx` — состояние, навигация и действия пользователя.
- `components/Views.jsx` — страницы кабинета.
- `components/Decision.jsx` — результат рассмотрения и недостающие данные.
- `lib/api.js` — HTTP-запросы и обработка ошибок API.
- `lib/demo.js` — отдельный демонстрационный режим с данными в браузере.
- `app/globals.css` — оформление.

Подключены регистрация, вход, профиль, компания, финансы, кредитная история,
продукты, черновики, отправка заявок, решения и audit history.
Поддержаны `NEED_MORE_DATA`, повторное рассмотрение той же заявки и показ
`MANUAL_REVIEW`. Кабинет проверяющего в этот интерфейс не входит.
API банковского предложения пока отсутствует; принятие предложения доступно
только в явно обозначенной демонстрации.

## Проверка

```sh
npm run build
```

Браузерные тесты: `npm run test:e2e`. По умолчанию они ожидают локальный
фронтенд на порту 3007; другой адрес задаётся переменной `APP_URL`.
Тесты с API включаются через `LIVE_BACKEND=1`; им нужна отдельная тестовая
база, поскольку они создают пользователей, компании и заявки.

Сборка и 9 браузерных сценариев проверены с backend из `dev`, коммит
`742e31cc93c9ee421858de67d0a3dd5a1dd5093a`, на изолированной PostgreSQL.
Для скоринга использовался штатный `Fallback_Rules` бэкенда без Ollama.
Windows-запуск в Linux-среде не проверялся.

В Git не добавляются `.env.local`, `node_modules`, `.next`, `.local-server.json`,
`test-results` и `playwright-report`. Зависимости перечислены в package.json
и package-lock.json; уведомления о лицензиях находятся в THIRD-PARTY-LICENSES.txt.
